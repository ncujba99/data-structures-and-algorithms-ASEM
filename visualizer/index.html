Лабораторная работа №5 — бинарное дерево (RU)
ЗАДАНИЕ 1

Вокзал на поисковом дереве

Добавление, поиск, удаление через предшественника, поиск по станции и три обхода — на живом дереве поездов.

 ЗАДАНИЕ 2

Дерево решений: кредит

Отвечайте ДА / НЕТ — путь подсвечивается до решения. Анимация подсчёта листьев (L = I + 1).

 ЗАДАНИЕ 3

Калькулятор на дереве выражения

Сортировочная станция → стек поддеревьев → вычисление обходом postorder. Пример методички = −13.
